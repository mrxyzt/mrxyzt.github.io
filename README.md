# Programmieraufgabe DIR

## Aufgabe 0: Vorbereitung

### Definition des Softwareprodukts

Bereitgestellt wird ein Webshop zum Vertrieb von Indie-Computerspielen in nicht-physischer Form. Es werden lediglich Spiele aus fremder Herstellung angeboten, insbesondere von kleinen Entwicklerstudios und Einzelentwickler:innen. Die Zielgruppe sind vor allem junge Erwachsene und Jugendliche, wobei sie nicht start Beschränkt ist.

### Definition des Unternehmens

**Name:** Indietruhe GmbH

**Standort:** Wien

**Anzahl Mitarbeiter:** 2

### Definition des Geschäftsmodells

Es wird lediglich Software im Einmalverkauf angeboten.


## Aufgabe 3: Marke

Es sollen folgende drei Marken geschützt werden:

- **Wortmarke:** "Indietruhe"
- **Bildmarke:** Logo in Farbe (*logo.svg*)
- **Farbmarke:** Oranger Hintergrund (*#ebae45*) mit hellbraunen (*#826229*) und dunkelbraunen (*#402d21*) Elementen darauf als Teil von Websites

Die Marken entsprechen der Nizza-Klasse 9 für herunterladbare Spielesoftware bzw. (aus Entwicklersicht) Klasse 35 für Dienstleistungen zur Verkaufsförderung über eine Website.

Für die zu schützenden Marken wurden mittels Recherche auf den Plattformen *TMview*, *Madrid Monitor* und *DuckDuckGo* keine Konflikte gefunden.
